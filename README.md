# GESP 三級練習室

可直接使用、上傳 GitHub Pages 的繁體中文練習網站。沒有套件安裝、建置步驟或後端。

## 快速使用

下載 ZIP 並解壓縮，開啟 `index.html` 即可練習。建議正式使用時部署到 GitHub Pages，以固定網址保留學習紀錄。部分瀏覽器會限制本機檔案的儲存功能；遇到提示時請先匯出備份。

## 上傳 GitHub Pages

1. 在 GitHub 建立儲存庫；使用免費 GitHub Pages 時可選公開儲存庫。
2. 把解壓縮後的**全部內容**上傳到儲存庫最上層：`index.html`、`styles.css`、三個 `.js` 檔，以及 `assets` 和 `downloads` 資料夾等。請勿只上傳 ZIP，也不要再包一層資料夾。
3. 提交檔案後，開啟儲存庫 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
5. Branch 選 **main**（若你使用另一個分支，選該分支），資料夾選 **/(root)**，按 **Save**。
6. 等部署完成，從 Pages 頁面提供的網站網址開啟。

網站使用相對路徑，支援 GitHub 專案網址下的子資料夾。`.nojekyll` 為空檔，可一併上傳；本網站沒有需要 Jekyll 處理的檔案。

官方操作說明：<https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site>

## 錯題與練習紀錄

1. 選擇答案後按「確認答案」，答錯會自動加入「我的錯題」。
2. 可以按「不會，存下來」手動標記；「不會，先看解說」也會加入錯題本，且不計為一次作答。
3. 在「我的錯題」按「重練這些題」，只練待複習的內容。
4. 答對後不會立刻移出錯題本；確認自己理解後按「我已理解，標記掌握」。之後仍可重新加入複習。
5. 每題的筆記、作答次數、答對次數、標記與編程草稿會自動保存。

累計正確率以客觀題的全部已提交作答計算；「已練客觀題」則是至少提交過一次的題目數。直接看解說不列入答題正確率。編程題的完成狀態由自己標記掌握。

## 保存、備份與換裝置

- 紀錄存在**目前裝置、目前瀏覽器、目前網站路徑**的 localStorage，不會寫回 GitHub，也不會自動同步到別的裝置。
- 開啟「備份與匯入」或側欄「匯出學習紀錄」，下載 JSON。檔案包含錯題、筆記、程式草稿及作答紀錄。
- 在另一台裝置開啟網站，選「匯入紀錄」，檢查摘要後確認。相同題目以較新的紀錄為準，不會重複加總答題次數。
- 清除網站資料、使用無痕模式、改網址、移動本機資料夾或換瀏覽器，可能使原有紀錄無法存取。建議定期匯出。
- 網站 ZIP 不含任何人的學習紀錄。個人 JSON 備份請自行保管，不必上傳公開儲存庫。
- 若畫面顯示無法儲存，請在關閉頁面前匯出。

## 編程題

可寫草稿、下載 `.cpp`、查看步驟與參考程式。此版本不在瀏覽器執行或自動評分 C++，請使用自己的編譯器或評測平台測試。參考解法以 C++11 撰寫。

## 檔案說明

| 檔案或資料夾 | 用途 |
| --- | --- |
| `index.html` | 網站入口 |
| `styles.css` | 桌面與手機版樣式 |
| `app.js` | 導覽、作答、筆記、篩選、備份操作 |

若更新題目，請保留原有題目的 `id`，讓使用者的紀錄繼續對應。新增題目請使用新的唯一 `id`。修改題目後也應同步更新顯示的總題數與說明。
